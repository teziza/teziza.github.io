Projects

What we have built so far.

Python encrypter

A command-line tool that encrypts and decrypts text with a password. A wrong password or edited text is detected, and the tool says so instead of returning garbage.

Language
Python 3, standard library only
Key derivation
PBKDF2-SHA256, 200,000 rounds, random salt
Encryption
SHA-256 keystream, random nonce
Integrity
HMAC-SHA256 tag
Status
Learning project

This is a custom design and has not been audited. Don't use it to protect anything important.
